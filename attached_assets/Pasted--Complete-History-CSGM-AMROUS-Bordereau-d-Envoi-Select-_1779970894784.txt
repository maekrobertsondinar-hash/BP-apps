🔒 Full App Expiry / Licence System
Built from scratch across three files:

utils/expiry.ts — Core licence engine: getLicenseData, saveLicenseData, clearLicense, getExpiryInfo, and touchLastKnownTime (tamper-detection by storing last known time and rejecting clock roll-backs). Licence data is stored XOR-encrypted in localStorage under key csgm_lic_v1.
components/ExpiryPanel.tsx — Admin-only management panel with two modes: set by exact date or set by number of days. Shows current status (valid/expired/days remaining), with save/clear/close actions.
App.tsx integration — State wiring, useEffect on app load to check expiry and touch the time, Ctrl+Shift+F12 keyboard shortcut to open the panel, a full-screen "Licence Expirée" overlay for expired non-admin users, and a warning banner that appears when ≤14 days remain.

📦 Smart Bordereau d'Envoi ZIP Import
Added an "Importer ZIP" button (sky blue) in the Bordereau header. It:

Accepts a .zip file previously exported from the app
Parses the exact folder/filename structure: {chantierName}/{Arrivee|Depart}_{YYYY-MM-DD}_{HHhMM}_{filename}
Reconstructs full BordereauEntry objects with correct chantier, type, date, filename, and MIME type
Merges with existing entries, skipping exact duplicates (same chantier + type + filename)
Auto-restores hidden chantiers and registers new chantiers as manual entries
Reports how many documents were imported and how many duplicates were skipped
Designed for full recovery after app reinstall or device change
