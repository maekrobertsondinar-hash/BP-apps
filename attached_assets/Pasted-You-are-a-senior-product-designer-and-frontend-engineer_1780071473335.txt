You are a senior product designer and frontend engineer improving an existing React + TypeScript + Vite app called CSGM AMROUS.

The app is already functional. Do not rebuild it from scratch. Preserve all existing business logic, data structures, IndexedDB/localStorage persistence, import/export behavior, authentication, user roles, licence expiry system, worker records, brevet/document handling, Bordereau d’Envoi, and all current features.

Your task is to perform a full UI/UX refinement and consistency pass across the entire application.

Context:
CSGM AMROUS is an internal industrial personnel and document management system. It manages workers, chantiers, functions, driver/grutier certificates, document previews, exports, imports, user approval, audit information, and Bordereau d’Envoi arrival/departure documents.

Current main problem:
The app is visually inconsistent. The login screen and some shell areas use a premium dark enterprise style, but many modals, tables, upload flows, Bordereau screens, and admin views still use light/white ERP surfaces or one-off styles. The result feels unfinished and fragmented.

Primary goal:
Transform the entire app into one cohesive, premium, dark enterprise desktop application. It should feel like high-end internal software for an industrial company: calm, powerful, fast, professional, and executive-grade.

Important constraints:
- Do not remove features.
- Do not break data compatibility.
- Do not change stored data keys unless migration is handled.
- Do not simplify the app by deleting functionality.
- Keep React, TypeScript, Vite, IndexedDB, localStorage, xlsx, JSZip, sql.js compatibility.
- You may use existing dependencies such as framer-motion and lucide-react.
- Prefer improving the existing component structure over rewriting everything.
- Ensure the app builds successfully after changes.

Design direction:
Use a cohesive dark enterprise design system inspired by Linear dark mode, Arc Browser, Raycast, Notion database dark mode, Airtable dark mode, modern cybersecurity dashboards, and premium fintech/admin tools.

Visual language:
- Deep navy/slate app background, not pure black.
- Layered dark panels with subtle contrast.
- Petroleum/steel blue identity accents.
- Controlled cyan highlights.
- Muted emerald, amber, and rose only for statuses.
- Subtle borders, soft shadows, restrained glow.
- Compact professional spacing.
- No childish colors, no generic Bootstrap look, no random white modals.
- Avoid giant rounded cartoon buttons.
- Avoid decorative gradient blobs/orbs except where already tasteful and restrained.

Create a reusable design system:
- Standardize colors, panel backgrounds, borders, shadows, radii, input states, buttons, badges, table rows, modal shells, empty states, and typography.
- Prefer 8px to 12px radii for normal controls and cards; use larger radii only for major modals or brand moments.
- Use consistent button variants: primary, secondary, ghost, danger, success, warning.
- Use lucide-react icons where practical instead of inconsistent inline SVGs.
- Keep typography compact and readable: strong hierarchy, no oversized dashboard text inside dense tools.
